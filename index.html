Run these SQL commands in your Supabase SQL Editor to set up the database for AgriScan Zambia.

SQL Setup Script

Run in Supabase SQL Editor
-- ============================================ -- AgriScan Zambia - Database Setup -- PostgreSQL / Supabase -- ============================================ -- 1. Create the scans table CREATE TABLE scans ( id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY, plant TEXT NOT NULL, disease TEXT NOT NULL, confidence INTEGER NOT NULL, recommendation TEXT, image_data TEXT, timestamp BIGINT NOT NULL, created_at TIMESTAMPTZ DEFAULT NOW() ); -- 2. Create indexes for performance CREATE INDEX idx_scans_plant ON scans(plant); CREATE INDEX idx_scans_disease ON scans(disease); CREATE INDEX idx_scans_timestamp ON scans(timestamp DESC); -- 3. Enable Row Level Security (RLS) ALTER TABLE scans ENABLE ROW LEVEL SECURITY; -- 4. Create RLS policies -- Allow all authenticated users to read CREATE POLICY "Allow read for all users" ON scans FOR SELECT USING (true); -- Allow all authenticated users to insert CREATE POLICY "Allow insert for all users" ON scans FOR INSERT WITH CHECK (true); -- Allow all authenticated users to update CREATE POLICY "Allow update for all users" ON scans FOR UPDATE USING (true); -- Allow all authenticated users to delete CREATE POLICY "Allow delete for all users" ON scans FOR DELETE USING (true); -- 5. Enable realtime for the scans table ALTER TABLE scans REPLICA IDENTITY FULL; ALTER PUBLICATION supabase_realtime ADD TABLE scans; -- 6. Create a view for aggregated stats CREATE OR REPLACE VIEW scan_stats AS SELECT COUNT(*) AS total_scans, COUNT(CASE WHEN disease = 'Healthy' THEN 1 END) AS healthy_count, COUNT(CASE WHEN disease != 'Healthy' THEN 1 END) AS infection_count, AVG(confidence) AS avg_confidence FROM scans;

Setup Instructions

Quick Start
  1. Create Supabase Project — Go to supabase.com and create a new project.
  2. Open SQL Editor — In your Supabase dashboard, navigate to the SQL Editor.
  3. Run the Script — Copy and paste the SQL script above into the editor and run it.
  4. Verify Table — Check that the scans table was created successfully in the Table Editor.
  5. Test Connection — The app will automatically connect to Supabase using the credentials in the JavaScript.
Security Note: Row Level Security (RLS) is enabled with policies that allow all operations. For production, you may want to restrict access using authentication.
